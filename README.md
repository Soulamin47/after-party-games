# AFTER!

Une app de soirée mobile avec six mini-jeux pour jouer entre amis, sans préparation.

## Jouer

**[Ouvrir AFTER!](https://soulamin47.github.io/after-party-games/)**

Les cinq jeux classiques sont ouverts pour les tests :

- Vérité ou Gage, avec un choix à chaque tour
- Mime ça !
- La Bouteille, avec un défi pour la personne pointée
- Qui de nous ?
- Défi éclair

**After Dark** est présenté comme un jeu coquin Premium réservé aux adultes. Il reste volontairement verrouillé dans la version de test.

## Développement

```bash
npm install
npm run dev
```

Créer la version GitHub Pages :

```bash
npm run build:pages
```

Le projet est construit avec React, TypeScript et Vite/vinext.
